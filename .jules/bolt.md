## 2024-04-16 - [Replace multi-pass array methods with single-pass loops]
**Learning:** In performance-critical components (like \`components/Profitability.tsx\`), calculating multiple aggregations (volume, margin, cost, etc.) using separate \`.reduce()\` calls on the same array causes redundant O(N) passes. Similarly, using \`.slice().reduce()\` creates temporary array allocations before iteration, increasing garbage collection pressure.
**Action:** Always replace multiple consecutive \`.reduce()\` operations over the same dataset with a single \`for\` loop that accumulates all values simultaneously. When calculating segment aggregations (e.g., first half vs second half), use a single \`for\` loop over the full array with index-based conditional logic instead of \`.slice().reduce()\`.
