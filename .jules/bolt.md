## 2026-06-11 - Array Iteration Consolidation
**Learning:** This codebase frequently performs multiple consecutive array operations (`.map()`, `.filter()`, `.sort()`, `.reduce()`) over the same large datasets (like `transactions`, `merchants`, or `draftLineItems`). When rendering complex dashboard components, these chained O(N) operations cause redundant passes over data and, in the case of `.sort()[0]`, introduce unnecessary O(N log N) complexity just to find a maximum value.
**Action:** Replace chained `.map().filter().sort()[0]` patterns with single O(N) loops that track the maximum value dynamically. Consolidate multiple independent `.reduce()` or `.filter()` calls into a single `for` loop to accumulate multiple totals simultaneously. This is especially critical in dashboard components like `ISODashboard` where 9 consecutive O(N) passes were merged into 1, significantly improving performance for large merchant lists.
