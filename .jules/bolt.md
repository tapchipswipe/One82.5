## 2026-06-03 - Prevent call stack exhaustion by converting chained map/max to a loop
**Learning:** Spreading a mapped array directly into Math.max (e.g., `Math.max(...merchants.map(...))`) in React component render cycles can cause a `RangeError: Maximum call stack size exceeded` for large datasets. Furthermore, chaining multiple independent `.filter`, `.reduce`, and `.map` calls for different metric aggregations over the same dataset results in redundant O(N) passes that harm performance.
**Action:** Replace multiple chained array methods (`.filter`, `.map`, `.reduce`) and spread operators for min/max calculations with a single, consolidated `for` loop to accumulate all necessary metrics simultaneously in one O(N) pass, enhancing safety and performance without severely impacting readability.
