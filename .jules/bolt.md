## 2026-07-05 - Consolidated Extrema Search Logic
**Learning:** Found an anti-pattern in React component `components/Dashboard.tsx` where `.map().filter().sort()[0] || null` was used solely to find a maximum value. This incurs an unnecessary $O(N \log N)$ cost and multiple full-array allocations, exacerbated when run inside a render loop or expensive hook. Additionally, the `|| null` fallback is unsafe for timestamp values that could be exactly `0`.
**Action:** Replaced chained array methods with a single $O(N)$ `for` loop tracking the maximum value explicitly, initializing with `-Infinity` and converting to `null` if unchanged. Ensure to use explicit `null` fallback logic (`if (val === -Infinity) val = null;`) instead of boolean evaluation (`|| null`) when dealing with numbers that can legitimately be `0`.
