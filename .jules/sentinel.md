## 2026-04-12 - [Insecure Randomness via Math.random()]
**Vulnerability:** Weak deterministic random number generation via Math.random() for security-related IDs (session tokens) and various other unique IDs across the application.
**Learning:** Math.random() should never be used for generating secure tokens or pseudo-random identifiers because its outputs can be predicted. Cryptographically secure random number generators (CSPRNG) like crypto.getRandomValues() should be utilized. Additionally, when patching TypeScript files that may run in environments where the global `crypto` object's types are not fully resolved, it is necessary to use `(crypto as any).getRandomValues(arr)` to bypass typechecking errors like `Property 'getRandomValues' does not exist on type 'never'`.
**Prevention:** Enforce a linting rule to prevent usage of Math.random() for tokens/IDs, and establish a centralized secure ID generation utility function that internally uses `crypto.getRandomValues()` or `crypto.randomUUID()`.
