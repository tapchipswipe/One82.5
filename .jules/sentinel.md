## 2025-02-14 - Predictable Session Tokens in Auth System
**Vulnerability:** Weak randomness (`Math.random()`) used to generate security-critical session tokens (`sessionId` and fallback for `createSessionToken`) in `api/_lib/backend.ts`.
**Learning:** `Math.random()` and `Date.now()` are deterministic and highly predictable. In an authentication context, using them to generate session IDs allows attackers to easily guess active session tokens and hijack user sessions, leading to a critical authorization bypass. A fallback mechanism that uses `Math.random()` when `crypto.randomUUID` is unavailable is dangerous security theater, as it silently downgrades to insecure token generation without warning.
**Prevention:** Never use `Math.random()` or time-based generation for cryptographic or security-critical purposes. Always rely on a cryptographically secure pseudo-random number generator (CSPRNG), such as Web Crypto API (`crypto.getRandomValues()` or `crypto.randomUUID()`). If secure randomness is unavailable, the system should fail securely by throwing an error rather than falling back to an insecure implementation.
