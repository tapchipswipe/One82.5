## 2024-05-24 - Weak Randomness for Session Tokens
**Vulnerability:** Weak random number generation (`Math.random()`) was being used alongside predictable data (`Date.now()`) to generate security-critical session tokens (`sessionId`, `sessionToken`) in `api/_lib/backend.ts`.
**Learning:** `Math.random()` generates easily predictable values and is cryptographically insecure. When used for authentication tokens, an attacker could predict session IDs or tokens and impersonate users, especially when combined with predictable time-based values like `Date.now()`. The code had a secure fallback but fell back to `Math.random()` when `crypto.randomUUID` was presumably unavailable, sacrificing security for availability.
**Prevention:** Always use cryptographically secure pseudo-random number generators (CSPRNG) like `crypto.randomUUID()` or `crypto.getRandomValues()` for any security-critical tokens, keys, or IDs. If a secure random number generator is not available in the environment, the application must fail securely by throwing an error rather than silently degrading to an insecure generation method.
